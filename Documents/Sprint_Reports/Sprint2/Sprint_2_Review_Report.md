## Sprint 2 Goal

The main goal of Sprint 2 was to establish the technical foundation of the **Edujournal – Teacher's Gradebook and Report Card System**.

The sprint focused on transforming the designs and requirements prepared during Sprint 1 into the first working parts of the application. The main areas of work were:

- MariaDB database implementation
- Initial JavaFX user interface development
- Maven project configuration
- JUnit unit testing
- JaCoCo code coverage
- Basic CRUD operations
- GitHub and Trello maintenance
- Preparation for the Sprint Review

# Sprint 4 – Sprint Planning Document

**Project:** Edujournal – Teacher's Gradebook and Report Card System  
**Sprint Duration:** 28.09.2026 – 04.10.2026

---

## 1. Sprint Goal

The goal of Sprint 4 is to complete the Edujournal project by finalizing the remaining application functionality, improving software quality through testing and bug fixing, creating and publishing a GUI-enabled Docker image for the JavaFX application, and preparing the system for the final project presentation and evaluation.

This sprint focuses on delivering a stable and fully functional product, validating its quality, collecting user feedback, and ensuring that the application can be distributed and demonstrated through a containerized graphical environment.

---

## 2. Sprint Objectives

The main objectives of Sprint 4 are:

- Finalize all remaining application features and improvements.
- Resolve outstanding functional and usability issues.
- Improve unit test coverage and software reliability.
- Generate and review JaCoCo code coverage reports.
- Create a GUI-enabled Docker image capable of running the JavaFX application.
- Publish the GUI Docker image to Docker Hub.
- Validate execution of the graphical application inside a Docker container.
- Conduct acceptance testing and gather feedback from classmates.
- Update project documentation.
- Prepare demonstration materials for the final project presentation.

## 7. Definition of Done

A task will be considered **Done** when:

- [ ] The implementation satisfies the defined acceptance criteria.
- [ ]  The application compiles and runs successfully.
- [ ]  Relevant unit tests have been created or updated.
- [ ]  All related tests pass successfully.
- [ ]  JaCoCo reports are generated where applicable.
- [ ]  The code has been reviewed by at least one team member.
- [ ]  The implementation has been committed and pushed to GitHub.
- [ ]  The corresponding Trello task has been updated.
- [ ]  Required documentation has been updated.
- [ ]  The completed functionality is ready for presentation and demonstration.
For Docker-related tasks:
- [ ] The GUI Docker image is successfully built.
- [ ] The GUI Docker image is published to Docker Hub.
- [ ] The JavaFX user interface launches correctly from the container.

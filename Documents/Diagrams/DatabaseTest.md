# Database Setup and Connection Test

## Create the database tables

When the project starts, `DatabaseInitializer` automatically creates the `edujournal` database if it does not exist.

It also creates the required database tables automatically.

No manual database or table creation is required.

## Create the default admin user

`DatabaseInitializer` automatically creates the default admin user if it does not exist.

## Test the database connection

Make sure MariaDB is installed and running on your computer.

You can also run DatabaseTest from IntelliJ IDEA to verify the database connection and initialization.
